# Clínica Luiza — Site institucional

Site de página única para a Clínica Luiza, psicóloga Angel Maria (CRP 01/27860-DF).

## Como publicar (GitHub Pages)

1. Faça upload do arquivo `index.html` para a raiz deste repositório.
2. Vá em **Settings → Pages**.
3. Em **Source**, selecione a branch `main` e a pasta `/root`.
4. Salve. O site fica disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPO` em alguns minutos.
5. (Opcional) Em **Custom domain**, adicione seu domínio próprio.

## Estrutura

- `index.html` — site completo (HTML, CSS e SVGs embutidos, sem dependências externas além de fontes do Google Fonts).
